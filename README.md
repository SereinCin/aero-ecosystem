# aero-ecosystem

> All Aero-written kernels, packages, and benchmarks in one place.
> Split by concern (kernels / packages / bench). Each subdirectory is a git subtree — preserves its original history.

## Structure

- \kernels/\ — Python C-extension kernels written in Aero (replaces: aero-jmespath, aero-jsonpath, aero-jsonl, aero-csv, aero-jmespath-bench)
- \packages/\ — Aero language ecosystem packages (replaces: Aero-packages)
- \ench/\ — Benchmark harness for all kernels (replaces: aero-bench)

## Archived repos (merged here)

These repos are **archived** on GitHub (read-only, still cloneable):

- aero-jmespath, aero-jmespath-bench → \kernels/jmespath/- aero-jsonpath → \kernels/jsonpath/- aero-jsonl → \kernels/jsonl/- aero-csv → \kernels/csv/- aero-bench → \ench/- Aero-packages → \packages/
